# BUG-09: Буруу JSON биетэй POST /api/books хүсэлтэд 400-ийн оронд 200 буцаана

Орчин: Уншлагын жагсаалт v2.0; Brave Browser 152.1.94.121 (Chromium суурьтай); Kali GNU/Linux 2026.1; Node.js v24.15.0; 2026-10-19.

Урьдчилсан нөхцөл: `node app.js`-ийг шинээр асаасан, анхны 3 номтой. Серверийг Ctrl+C-ээр зогсоож дахин асаахад өгөгдөл анхны төлөвт орно.

## Дахин гаргах алхам

1. `http://localhost:3000` сервер ажиллаж байгааг шалгана.
2. Терминалд доорх curl командыг ажиллуулна.
3. HTTP статусын мөр болон хариуны биеийг шалгана.

Хүлээгдэж байсан: Буруу JSON биетэй POST хүсэлтэд HTTP 400 буцаана.

Бодит үр дүн: 2026-10-19 22:55:53 (+08)-д зөв хэлбэртэй curl командаар дахин шалгахад `HTTP/1.1 200 OK`, `{"result":"OK"}` буцсан.

Ноцтой байдал: Major — API хүчингүй хүсэлтийг амжилттай гэж мэдээлж байна.

Олдсон аялал: Saboteur.

## Нотолгоо

```bash
mkdir -p evidence
curl -sS -i -X POST http://localhost:3000/api/books \
  -H 'Content-Type: application/json' \
  --data-binary '{"title":' \
  -o evidence/bug-09-curl.txt
```

[HTTP статусын мөр, header болон body бүхий бүтэн гаралт](../evidence/bug-09-curl.txt).

Анхны `evidence/invalid-json-curl.txt`-ийг хэвээр хадгалсан; тухайн терминалын зурагт curl URL-ийн алдаа байсан тул тусдаа зөв командаар дахин баталгаажуулав.
