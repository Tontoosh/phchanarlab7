# BUG-01: Анхны 3 номтой хүснэгтийн «Нийт ном» тоолуур 4 гэж харагдана

Орчин: Уншлагын жагсаалт v2.0; Brave Browser 152.1.94.121 (Chromium суурьтай); Kali GNU/Linux 2026.1; Node.js v24.15.0; 2026-10-19.

Урьдчилсан нөхцөл: `node app.js`-ийг шинээр асаасан, анхны 3 номтой. Серверийг Ctrl+C-ээр зогсоож дахин асаахад өгөгдөл анхны төлөвт орно.

## Дахин гаргах алхам

1. `http://localhost:3000` нээнэ.
2. Хайлтын үг оруулахгүйгээр хүснэгтийн өгөгдлийн мөрүүдийг тоолно.
3. Хүснэгтийн доорх «Нийт ном» утгатай харьцуулна.

Хүлээгдэж байсан: «Нийт ном» хүснэгт дэх номын тоотой тэнцүү буюу 3 байна.

Бодит үр дүн: Зурагт 3 номтой боловч «Нийт ном: 4» гэж харагдана.

Ноцтой байдал: Minor — хэрэглэгчид номын тоог буруу мэдээлж байна.

Олдсон аялал: Fed-Ex.
